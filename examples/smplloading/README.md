# SMPL Loading

A tool to visualize the human generated by smpl.

![](../../screenshots/smplloading_0.png)

## How to use

### Step 1. Generate the smpl model

1. Set up the python environment(Optional)

    ```python
    conda create -n {env_name} python=3.7.12
    conda activate {env_name}
    pip install librosa==0.8.1 numpy==1.19.2 scipy==1.7.3
    conda install pytorch==1.8.0 -c pytorch
    pip install smplx==0.1.26 trimesh==3.9.29 vedo==2021.0.3 chumpy
    ```

2. Import [`dump_smpl_model.py`](\\dine\Graphics_Shanghai\users\yuandiz\VulkanTools\SMPLVisTool\dump_smpl_model.py) and pass `motion_pkl` to generate model's info. The default path is `C:\\smpl_model\\` . Refer to [`dump_smpl_model_test.py`](\\dine\Graphics_Shanghai\users\yuandiz\VulkanTools\SMPLVisTool\dump_smpl_model_test.py) for how to use it.

    ```python
    dump_smpl_model = DumpSmplModel(motion_pkl)
    dump_smpl_model.generate_model()
    ```

3. Check the files `config.json, index.bin, vertices.bin` are generated successfully

### Step 2. Run the Vulkan APP

#### Windows

- Run [`smplloading.exe`](\\dine\Graphics_Shanghai\users\yuandiz\VulkanTools\SMPLVisTool\Windows\smplloading.exe), and it will read the files generated in Step 1. The default path is `C:\\smpl_model\\`, or pass the folder by `--root-folder`.

    ```shell
    .\smplloading.exe --root-folder \\dine\Graphics_Shanghai\users\yuandiz\VulkanTools\SMPLVisTool\smpl_model
    ```

#### Android

- Push the model file to device's folder `/data/local/tmp/smpl_model/`

    ```shell
    adb push .\smpl_model\ /data/local/tmp
    ```

- Install the [`smplloading-debug.apk`](\\dine\Graphics_Shanghai\users\yuandiz\VulkanTools\SMPLVisTool\Android\smplloading-debug.apk)

    ```shell
    adb install .\smplloading-debug.apk
    ```

- Run the app

    ```shell
    adb shell am start -n de.saschawillems.vulkanSmplLoading/de.saschawillems.vulkanSample.VulkanActivity
    ```
